# Kategoriya rasmlari

Bu papkaga qo'yilgan rasm ilovada kategoriya kartasida chiqadi.

- Fayl nomi quyidagi jadvaldagidek bo'lsin (`.jpg`)
- O'lchami kvadrat, ~500x500, 100 KB atrofida
- Fon oq bo'lsa chiroyliroq chiqadi

Fayl qo'shilgandan keyin `index.html` dagi `CAT_IMG` ro'yxatiga ham qo'shiladi —
aks holda ilova uni qidirmaydi.
